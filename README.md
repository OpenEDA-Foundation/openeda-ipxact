# OpenEDA IP-XACT

OpenEDA IP-XACT is an independent open-source IEEE 1685 IP-XACT domain platform.

## Status

Early foundation development.

Canonical standard:

- IEEE 1685-2022

Primary implementation:

- Rust 2024
- Stable Rust toolchain
- Cargo workspace

License:

- Apache-2.0

## Architecture

OpenEDA IP-XACT provides a semantic domain model independent from XML, GUI frameworks, AWorldMagic, Kactus, and any specific EDA Workbench.
